BACHELOR’S THESIS · SIEMENS

Hybrid Multimodal RAG for IT Support

Designed, built, and evaluated a retrieval augmented generation system for Siemens’ Global Integration Layer team, bringing together 3,569 Jira tickets and a Confluence wiki of 2,603 pages.

  • Combined BM25 with SentenceTransformer embeddings in FAISS; the best wiki configuration reached Precision@5 = 0.760, 36% above BM25 alone and 31% above dense retrieval alone.
  • Added LLaVA vision augmentation to index diagrams, reaching the best ranking quality with MRR@5 = 0.693.
  • Ran models locally with Ollama and Qwen3.5 so Siemens data stays within the company; evaluated 150 handwritten questions with an LLM as Judge score of 3.78/5.

↗ The recommended system configuration is being implemented at Siemens.

  • Python
  • FAISS
  • SentenceTransformers
  • LLaVA
  • Ollama
